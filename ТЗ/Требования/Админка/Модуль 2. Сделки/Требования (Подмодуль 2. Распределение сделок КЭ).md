**Описание подмодуля:**
Подмодуль предназначен для распределения заявок в статусе "На рассмотрении нач. КЭ" (или другой статус).
Распределение осуществляется начальником отдела кредитных экспертов (роль - админ) между кредитными экспертами Центра лизинга.


#### **Требования 1.1.:** Отображение лизинговых сделок

**Описание:**
Система должна отображать список сделок в виде таблицы с пагинацией
Поля таблицы: 
1. ID сделки
2. УНП клиента
3. Наименование клиента
4. Предмет лизинга
5. Менеджер
6. Статус
7. Сумма
8. Дата создания
9. Действия

**Детали:**
1. Система отображает общее количество сделок. (небольшая отметка о том, сколько сделок отображено в таблице модуля)
2. Сортировка по умолчанию: по ID сделки от большего к меньшему значению DESC
3. В колонке действия на каждой строке сделки размещаются функциональные кнопки: просмотреть карточку клиента, и выпадающий список с сотрудниками с ролью "Кредитный эксперт"
4. Отображаются ТОЛЬКО сделки в статусе "На рассмотрении нач. КЭ" 


#### **Требования 1.2:** Распределение заявок на кредитных экспертов

**Описание**: Система должна предоставлять функционал распределения заявок в Подмодуле 2 (этот модуль)

**Детали**: 
1. В таблице сделок в колонке "действия" есть выпадающий список, где можно выбрать Кредитного эксперта, который будет рассматривать сделку.
2. После того, как начальник кредитных экспертов расставит напротив каждой сделки ответственного кредитного эксперта, ему необходимо нажать на кнопку "Распределить" в шапке таблицы, чтобы записать каждой сделке определенного кредитного эксперта.
3. Кнопка "Распределить" не доступна, пока не выбран хотя бы один кредитный эксперт.
4. После нажатия "Распределить":
   - Статус сделки меняется на "В рассмотрении КЭ"


#### **Требование 1.3:** Просмотр карточки сделки
**Описание:** Требования идентичны из "Подмодуля 1. Сделки". 
Необходимо сделать редирект на карточку сделку.
