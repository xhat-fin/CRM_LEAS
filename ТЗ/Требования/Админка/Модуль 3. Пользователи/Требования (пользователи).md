**Описание модуля:**
Модуль предназначен для работы с зарегистрированными пользователями - сотрудниками Центра лизинга.

#### **Требование 1.** Отображение пользователей

**Описание**: в модуле 3. Пользователи отображаются только пользователи без отметки об удалении, то есть у которых в столбце "Дата удаления" таблицы Users = NULL.


##### **Требование 1.1.** Отображение пользователей на главной странице модуля

**Описание:** Система должна отображать пользователей в виде карточек. Одна карточка - один пользователь.
Необходимые поля в карточке пользователя: 
1. ID пользователя
2. Дата создания (дата регистрации)
3. Последняя дата обновления
4. Роль
5. Команда


##### **Требование 1.2.** Фильтры для отображения пользователей

**Описание:** Система должна отображать пользователей по определенно выставленным фильтрам.

**Детали:**
Виды фильтров: 
1. Роль - выпадающий список из справочника ролей (Модуль 4. Конфигурация. Справочник 2)
2. По имени пользователя - пользователь вводит необходимое значение для поиска в текстовое поле. Фильтрация происходит таким образом, что отбирает всех пользователей, у которых в ФИО есть хоть какая-то часть введенных символов в любом регистре (ILIKE SQL).
3. Команда - выпадающий список из справочник Команд (Модуль 4. Конфигурация. Справочник 11)

- Другое: 
1. Применение фильтров происходит после нажатия на кнопку "применить".
2. Если фильтр не дал результатов, то в таблице появляется одно поле "Пользователи не найдены"
3. Должна быть кнопка "Сбросить фильтры". Кнопка работает без подтверждения. 


##### **Требования 1.3:** Просмотр карточки пользователя

**Описание**: Система должна иметь возможность просмотра карточки пользователя

**Детали:**
1. Отображаемые поля: 
   - username
   - ФИО
   - Роль
   - Команда пользователя
   - Дата регистрации
   - Дата обновления


#### **Требования 2. Операции над пользователями**

##### **Требование 2.1: Редактирование пользователя**

**Описание**: Система должна иметь возможность редактирования карточки пользователя.

**Детали**:
- Форма редактирования:
1. ФИО пользователя
2. username
3. Роль (выпадающий список из справочника ролей. Модуль 4. Конфигурация. Справочник 2)
4. Команда пользователя (выпадающий список из справочника Команд. "Модуль 4. Конфигурация. Справочник 11")


##### **Требования 2.2:** Удаление пользователя (soft delete)

**Описание**: Система должна иметь возможность удалить пользователя из отображения на главной странице модуля.

**Детали**: 
1. Удаление происходит путем проставления даты удаления в базе данных записи о пользователе.
2. После нажатия на кнопку удалить система запрашивает подтверждение от пользователя модальным окном: "Удалить пользователя?" - Кнопки:  "Да", "Нет".
3. Да - flash уведомление "Пользователь удален"
4. Нет - отмена операции (ничего не происходит)
